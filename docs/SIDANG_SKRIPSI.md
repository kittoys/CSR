# Dokumentasi Sidang Skripsi

## Project: Sistem Informasi Manajemen Program CSR

## 1. Latar Belakang

Perkembangan program Corporate Social Responsibility (CSR) saat ini menuntut adanya sistem yang mampu mengelola data program, proposal, dan pelaporan secara terstruktur. Sebagian besar proses masih dilakukan secara manual, sehingga rentan terhadap keterlambatan, kesalahan pencatatan, dan kurangnya transparansi.

Oleh karena itu, dibangun sebuah sistem berbasis web untuk membantu pengelola CSR dalam mengelola program secara lebih efektif, efisien, dan terintegrasi.

## 2. Rumusan Masalah

Berdasarkan latar belakang tersebut, beberapa permasalahan yang menjadi fokus penelitian adalah:

- Bagaimana merancang sistem informasi CSR yang dapat mengelola program dan proposal secara terpusat?
- Bagaimana membuat sistem yang memudahkan admin dalam menginput, mengedit, dan memantau data program?
- Bagaimana menyediakan dashboard yang memudahkan pemantauan status proposal secara real-time?

## 3. Tujuan Penelitian

Tujuan dari pengembangan sistem ini adalah:

- Membangun sistem informasi CSR yang terorganisir dan mudah digunakan.
- Memfasilitasi admin dalam mengelola data program dan proposal.
- Menyediakan dashboard untuk memantau perkembangan proposal secara lebih cepat dan akurat.

## 4. Manfaat Penelitian

Manfaat dari sistem ini antara lain:

- Mempercepat proses pengelolaan program CSR.
- Meningkatkan akurasi dan keteraturan data.
- Mempermudah monitoring status proposal.
- Memberikan kemudahan akses bagi admin melalui antarmuka web.

## 5. Ruang Lingkup Sistem

Sistem ini mencakup beberapa fitur utama, yaitu:

- Login admin
- Manajemen program CSR
- Manajemen kategori
- Pengelolaan proposal donasi
- Upload dokumen pendukung
- Dashboard statistik proposal
- Filter dan pencarian data
- Tampilan responsive untuk desktop dan mobile

## 6. Metode Pengembangan

Sistem ini dikembangkan menggunakan pendekatan berbasis web dengan arsitektur client-server, yaitu:

- Frontend: React
- Backend: Node.js dan Express
- Database: MySQL
- Authentication: JWT
- File upload: multer

Proses pengembangan meliputi:

1. Analisis kebutuhan sistem
2. Perancangan database dan arsitektur
3. Implementasi fitur backend dan frontend
4. Pengujian sistem
5. Evaluasi dan perbaikan

## 7. Arsitektur Sistem

Secara umum, arsitektur sistem terdiri dari tiga bagian utama:

- Frontend: menyediakan antarmuka pengguna untuk admin dan publik
- Backend: menangani proses bisnis, autentikasi, dan API
- Database: menyimpan data program, kategori, proposal, dan user

Alur kerja sistem:

1. Admin melakukan login
2. Admin mengelola program dan proposal
3. Data disimpan ke database
4. Sistem menampilkan data melalui dashboard dan halaman pengguna

## 8. Fitur Utama yang Dikembangkan

Beberapa fitur yang menjadi fokus utama sistem adalah:

- Login dan autentikasi admin
- CRUD program CSR
- CRUD kategori
- CRUD proposal
- Upload file pendukung
- Dashboard statistik proposal
- Filter status dan pencarian data
- Tampilan antar muka yang lebih konsisten dan mudah dipahami

### 9.1. Menjalankan Aplikasi

## 10. Hasil yang Dicapai

Sistem yang dibangun telah mampu:

- Mengelola data program CSR dengan lebih terstruktur
- Mempermudah admin dalam mengelola proposal
- Menyediakan dashboard monitoring yang informatif
- Meningkatkan efisiensi kerja dibandingkan sistem manual

## 11. Kelebihan Sistem

- Antarmuka yang mudah dipahami
- Proses pengelolaan data lebih cepat
- Data tersimpan terpusat di database
- Fitur upload dan dashboard memudahkan monitoring

## 12. Keterbatasan Sistem

Beberapa keterbatasan yang masih ada antara lain:

- Sistem masih fokus pada kebutuhan admin dan manajemen proposal
- Fitur laporan lebih lanjut dapat dikembangkan lagi
- Integrasi dengan sistem eksternal belum diterapkan

## 13. Kesimpulan

Sistem informasi manajemen program CSR yang dikembangkan ini berhasil memberikan solusi untuk mengelola program, kategori, dan proposal secara lebih terorganisir. Dengan fitur login, CRUD, upload file, dan dashboard statistik, sistem ini dinilai mampu meningkatkan efisiensi dan transparansi dalam pengelolaan program CSR.

## 14. Saran Pengembangan

Beberapa pengembangan yang dapat dilakukan ke depan adalah:

- Menambahkan fitur notifikasi
- Menyediakan export laporan PDF/Excel
- Mengembangkan dashboard analitik yang lebih lengkap
- Menambahkan role user lebih dari satu level

## 15. Penutup

Dengan adanya sistem ini, proses pengelolaan program CSR dapat dilakukan secara lebih modern, terstruktur, dan efisien. Sistem ini diharapkan dapat menjadi dasar untuk pengembangan aplikasi CSR yang lebih luas di masa depan.
